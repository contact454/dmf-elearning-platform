# Tagging Rules

## Content Hierarchy
*   Level (A1, A2)
    *   Unit
        *   Lesson
            *   Activity

## Tagging Schema
All content MUST be tagged with:
1.  **CEFR Level**: strict `A1.1` to `C2`
2.  **Skill Type**: `Reading`, `Listening`, `Speaking`, `Writing`, `Grammar`, `Vocabulary`
3.  **Topic**: e.g., `Family`, `Travel`, `Business`
