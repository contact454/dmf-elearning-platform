# Events Catalog

**Topic Format**: `domain.entity.action`

## Learning Domain
*   `learning.lesson.started` - User opens a lesson
*   `learning.lesson.completed` - User finishes lesson (pass/fail)
*   `learning.lesson.abandoned` - User quits mid-session
*   `learning.submission.created` - User submits an answer

## Assessment Domain
*   `assessment.quiz.started`
*   `assessment.quiz.submitted`
*   `assessment.level_test.completed`

## Curriculum Domain
*   `curriculum.unit.unlocked`
*   `curriculum.course.enrolled`
*   `curriculum.srs_items.due`

## Mentoring Domain
*   `mentoring.feedback.requested`
*   `mentoring.feedback.published`

## System/User
*   `system.user.registered`
*   `system.user.login`
*   `system.profile.updated`
