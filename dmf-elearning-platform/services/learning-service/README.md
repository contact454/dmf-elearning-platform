# Learning Service API

Backend service providing German vocabulary data from the Resource Hub.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Development mode (with hot reload)
npm run dev

# Build for production
npm run build

# Run production
npm start
```

## 📡 API Endpoints

Base URL: `http://localhost:3003/api`

### Health Check
```
GET /health
```
Returns service status and timestamp.

### Get All Levels
```
GET /resources/levels
```
Returns list of available CEFR levels (A1, A2, B1, B2, C1, C2).

**Response:**
```json
{
  "success": true,
  "data": {
    "levels": ["A1", "A2", "B1", "B2"],
    "count": 4
  }
}
```

### Get Topics for a Level
```
GET /resources/:level/topics
```
Returns list of topics available for a specific level.

**Example:** `GET /resources/A1/topics`

**Response:**
```json
{
  "success": true,
  "data": {
    "level": "A1",
    "topics": ["Conjunctions", "Family_name", "Food"],
    "count": 3
  }
}
```

### Get Vocabulary for a Topic
```
GET /resources/:level/:topic
```
Returns vocabulary data for a specific level and topic.

**Example:** `GET /resources/A1/Conjunctions`

**Response:**
```json
{
  "success": true,
  "data": {
    "topic": "Conjunctions",
    "level": "A1",
    "vocabulary": [
      {
        "word": "so",
        "pos": "intj",
        "meaning_vi": "used to indicate addition",
        "source": "kaikki.org",
        "addedAt": "2026-01-31T16:40:39.004Z"
      }
    ],
    "count": 1
  }
}
```

### Get Level Summary
```
GET /resources/:level/summary
```
Returns summary statistics for a level.

**Example:** `GET /resources/A2/summary`

**Response:**
```json
{
  "success": true,
  "data": {
    "level": "A2",
    "topicCount": 55,
    "topics": ["Conjunctions", "Food", ...]
  }
}
```

### Clear Cache (Admin)
```
POST /resources/cache/clear
```
Clears server-side cache.

**Request Body:**
```json
{
  "key": "optional_cache_key" // Omit to clear all cache
}
```

## 🗂️ Architecture

```
src/
├── controllers/
│   └── ResourceController.ts  # API request handlers
├── services/
│   └── ResourceService.ts     # Business logic + caching
├── routes/
│   ├── index.ts               # Route aggregator
│   └── resources.ts           # Resource routes
├── types/
│   └── index.ts               # TypeScript interfaces
└── index.ts                   # Express server
```

## 🔧 Features

- **Caching:** 5-minute TTL cache using `node-cache`
- **Error Handling:** Retry logic for files being written by Data Factory
- **Validation:** CEFR level format validation (A1-C2)
- **CORS:** Enabled for frontend integration
- **Hot Reload:** Automatic restart on code changes (dev mode)

## 🌐 Environment Variables

Create `.env` file:
```
PORT=3003
NODE_ENV=development
```

## 📊 Data Source

Vocabulary data is generated by the German Data Factory (PM2 daemon) and stored in:
```
storage/resource-hub/
├── A1/
│   ├── Conjunctions.json
│   ├── Food.json
│   └── ...
├── A2/
├── B1/
└── ...
```

## 🐛 Error Handling

- **400 Bad Request:** Invalid level format
- **404 Not Found:** Level or topic doesn't exist
- **500 Internal Server Error:** File read errors or server issues

All errors return:
```json
{
  "success": false,
  "error": "Error message"
}
```
